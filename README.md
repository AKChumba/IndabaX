# IndabaX Namibia 2026 Official Website

This repository contains the source code for the official website of **IndabaX Namibia 2026**, the premier local community-led conference celebrating and advancing research and development in Artificial Intelligence, Machine Learning, and Data Science within Namibia.

##  About the Project

The website serves as the central hub for the IndabaX Namibia 2026 event. It provides attendees, speakers, and sponsors with essential information regarding:
*   **Event Schedules & Keynotes**
*   **Speaker Profiles & Panel Discussions**
*   **Hackathons & Interactive Workshops**
*   **Sponsorship Packages & Community Partners**
*   **Registration & Venue Details**
